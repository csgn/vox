# Roadmap

Built one milestone at a time; each ships with tests, docs, and a changelog entry.

| Milestone | Version | Scope | Status |
|---|---|---|---|
| M0 | 0.1.0 | Skeleton: open, render, scroll, `:q` | done |
| M1 | 0.2.0 | Core editing: transactions, undo tree, insert/normal, basic motions, `:w` | |
| M2 | 0.3.0 | Vim grammar: operators × motions × text objects, counts, registers, dot-repeat, visual, search, macros | |
| M3 | 0.4.0 | Developer API (`vox-api`, `vox-std`), TOML config, configurable keymaps | |
| M4 | 0.5.0 | Windows/splits, buffer list, picker, tree-sitter highlighting, themes | |
| M5 | 0.6.0 | WASM plugins: WIT contract, host, Rust SDK, examples, hot reload | |
| M6 | 0.7.0 | Claude: `claude` CLI stream-json, chat pane, editor MCP tools, diff review | |
