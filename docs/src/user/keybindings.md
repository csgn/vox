# Keybindings

Not configurable yet (planned for M3).

## Normal mode

| Key | Action |
|---|---|
| `j`, `Down` | scroll down one line |
| `k`, `Up` | scroll up one line |
| `Ctrl-d` / `Ctrl-u` | scroll half page down / up |
| `Ctrl-f` / `Ctrl-b` | scroll page down / up |
| `PageDown` / `PageUp` | scroll page down / up |
| `gg` | top of file |
| `G` | bottom of file |
| `:` | enter command line |

## Command line

| Key | Action |
|---|---|
| `Enter` | execute |
| `Esc` | cancel |
| `Backspace` | delete char; on empty input, cancel |
